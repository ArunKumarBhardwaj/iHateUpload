# iHateUpload

Free browser tools that never upload your files.

## Tools

- **HEIC → JPG** for iPhone photos
- **Compress Image** for JPG, PNG, WebP
- **Image → PDF** for combining photos into one document

Everything runs client-side with `heic2any`, `browser-image-compression`, and `pdf-lib`.

## Run locally

```bash
bun install
bun run dev
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Stack

Next.js, TypeScript, Tailwind CSS, shadcn/ui. Package manager: Bun.

## Domain

Suggested production domain: `ihateupload.com` (~$10–15/year).
